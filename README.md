## 配音提示

几处双关梗容易踩坑，已在台词本「备注」列标出：

- `in a pickle` —— 陷入困境／酸黄瓜
- `hold the mayo` —— 不要蛋黄酱／抱住蛋黄酱（派大星真的举起了罐子）
- `with relish` —— 津津有味／酸黄瓜酱
- `broke` —— 破产／身无分文
- 蟹老板把 `formula` 念成 `formuler`，是角色口音梗，不要念标准音

整段 5 分钟里纯人声约 2 分半，其余是音效与爆炸场面，实际配音压力不大。
